# Authentic Representation Project

## Overview

The Authentic Representation Project is a research and data repository focused on disability representation, authentic casting, and media inclusion in UK television drama. The project brings together annual production reports, actor datasets, casting analyses, and research prompts to support evidence-based evaluation of representation trends from 2021 to 2025.

## Purpose

This repository was created to:

- Track disability representation across UK television drama productions
- Analyze annual casting patterns and trends
- Maintain actor and disability-category datasets for longitudinal review
- Support regulatory and policy critique around authentic portrayals
- Consolidate research materials, reports, and project documentation in one place

## Repository Structure

### Annual Production Reports
The repository contains yearly case-study folders for the major production reporting periods:

- `2021 Final TV Production report/`
- `2022 Final TV Production Report/`
- `2023 Final TV Production Report/`
- `2024 Final TV Production Report/`
- `2025 Final TV Production Report/`

Each folder contains:

- annual comparison reports in Excel format
- summary documents in Word format
- related statistics and reporting outputs

### Actor Data Sets
The project includes core actor and disability-category records used to support analysis and narrative reporting:

- `Actor Data Sets/Established_Disability_Category_Register_Final.xlsx`
- `Actor Data Sets/Established_Disability_Category_Register_Apparent_Disability_Subset.xlsx`
- `Actor Data Sets/Old actor data sets/`

These files provide historical and current versions of the actor register and disability classification datasets.

### Casting Data and Carry-Forward Analysis
The repository contains master datasets and cumulative carry-forward resources for multi-year analysis:

- `2021_2025_Combined_Annual_Casting_Activity_Master.xlsx`
- `Carried Over Casting Data/`
- `British TV productions 2021 to 2025 - updated.xlsx`

These files capture annual developments, repeated appearances, and cumulative casting activity across the project period.

### Analytical Outputs
The repository includes detailed narrative and tabular outputs exploring representation and regulatory issues:

- `Apparent_Disability_Proportions_UK_Report.docx`
- `BBC_Disability_Portrayal_Regulatory_Critique.docx`
- `UK_Television_Drama_Disability_Casting_Tabular_Data.docx`
- `UK_Television_Drama_Disability_Casting_Text_Only.docx`
- `Jack Thorne's Main points.docx`

### BBC-Focused Reporting
A dedicated folder for BBC-related analyses is also included:

- `Final Data Outputs for BBC Only commissions/`

This section contains BBC-focused production analyses and themed outputs relevant to commissioning and representation.

### Research Methodology and Prompts
The project includes its research process documentation and prompt files:

- `Prompts and RAGs/`
- `Performer_Disability_Research_Methodology_RAG_v1.0.docx`
- `Performer_Disability_Self-Disclosure_Research_RAG_v1.0.docx`
- `Prompt - PERFORMER DISABILITY RESEARCH.docx`
- `Data Prompt.docx`

These materials support consistent data collection and disability research methods.

## Research Focus

The project examines:

- disability representation in UK television drama
- authentic casting practices
- actor disclosure and representation categories
- patterns in annual casting and production activity
- BBC and wider regulatory contexts
- longitudinal evidence across multiple reporting years
